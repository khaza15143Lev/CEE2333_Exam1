2D Truss FEM — 25-Version Exam Assignment

Assembling the 3rd element into an 8×8 global system — free joint and inclined element vary by version

Score: 0 / 2175 fields correct (0 / 25 problems fully solved)

General Setup (applies to all 25 problems below)

Each problem is a pin-jointed 2D truss with 4 nodes: one free joint loaded by a point force, and three pinned supports (fixed in both x and y). The truss has three members — one horizontal, one vertical, and one inclined — each connecting a support directly to the free joint. Which node number is the free joint, and which element number (1, 2, or 3) is the inclined one, both change from problem to problem.

Degree-of-freedom (DOF) numbering: for Node n, the x-displacement is global DOF 2n − 1 and the y-displacement is global DOF 2n. With 4 nodes, the full system has 8 DOFs, so the global stiffness matrix is 8×8 and the global load vector is 8×1.

Each member's stiffness contribution (in global coordinates) is k·[[c², cs, −c², −cs], [cs, s², −cs, −s²], [−c², −cs, c², cs], [−cs, −s², cs, s²]], ordered [free node x, free node y, support node x, support node y], where k = EA/L and c, s are the direction cosines from the support to the free joint. At the beginning of each problem, the two axis-aligned members have already been assembled into the 8×8 global stiffness matrix; every other entry (including the whole row/column pair for the inclined member's support node) is still zero.

Task — for each problem:

  1. a. Form the stiffness matrix for the inclined (3rd) element.
  2. b. Add it to the global (8×8) stiffness matrix.
  3. c. Form the global (8×1) load vector.
  4. d. Apply boundary conditions.

You may revise and resubmit any part as many times as you like.

            Rayleigh–Ritz Method — Interactive Assignment

            Elastic energy, external work, coefficient a, strain, and stress — 15 self-checking problems

            Score: 0 / 75 steps correct (0 / 15 problems fully solved)

            General Setup (applies to all 15 problems below)

            Consider a bar of length L, fixed at x = 0 and free at x = L. The bar carries a distributed axial load per unit volume q(x) acting along its full length, together with two concentrated loads P/2 applied symmetrically above and below the neutral axis at the cross-section x = L0 (their combined effect is a single net axial force P at that section, with no bending moment).

            The total potential energy of the bar, for an assumed admissible displacement field u(x), is

            Π(a) = U(a) − W(a),    U(a) = ½ EA∫0L (u′)² dx,    W(a) = ∫0L q(x) u(x) dx + P·u(L0)

            Task: for each problem, using the trial field u(x) = a·xn (which satisfies u(0) = 0), work through the Rayleigh–Ritz method and enter your answer for each of the five steps below. You may revise and resubmit any step as many times as you like.

            1. Elastic strain energy coefficient — evaluate U(a) = ½EA∫(u′)²dx using Gauss quadrature (1, 2, or 3 points, matching the order n of the trial field), and report the numerical coefficient of a² (i.e. U(a)/a²).
            2. External work coefficient — evaluate W(a) = ∫q(x)u(x)dx + P·u(L0) using Gauss quadrature (as many points as needed), and report the numerical coefficient of a (i.e. W(a)/a).
            3. Value of a — set dΠ/da = 0 and solve for a.
            4. Strain — using your value of a, compute the axial strain ε(x) = u′(x) at x = L.
            5. Stress — using E = 100, compute the axial stress σ(x) = E·ε(x) at x = L.

            Note: take E = 100 and A = 0.01 (so EA = 1, as before) and P = 10 (consistent units) for every problem below.
